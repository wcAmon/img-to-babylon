| 方案 | 行為與取捨 |

| A：第一人稱走動＋人偶雙手連動（建議） | 同一個人偶在場景中走動，視角從眼睛看出去；雙手跟隨實體器材的握點，配合站點提示學習。能連續練習搬運、清理和廢棄物處理，需要補手部姿勢、手臂求解與抓取輸入。 |
| B：第一人稱走動＋各站固定操作姿勢 | 到站後進入穩定的操作視角，以預設手部動作逐項練習。教學取景較容易控制，但搬運與自由操作的連續感較弱。 |

A 仍可在精細操作時暫時固定視角，兼顧自由走動與清楚示範。

**第一人稱必須看見「自己的手在操作」**

保留完整人偶的身體、肩膀、手臂與雙手。鏡頭取角色眼睛位置，頭部和頭髮只對自身鏡頭隱藏，避免從頭內部看到模型表面；低頭仍能看見身體、手臂和拿取的器材。鏡頭高度與視角依模型眼點和可視範圍調校，移動時採穩定視線。

手部需要能辨識掌面、手背、拇指與握持方向。沿用程序化建模，為訓練人偶補上簡化手掌與手套外觀，以有限幾種握姿表達動作：放鬆、握把、雙手托持、捏持、按壓。手套狀態同時更新手掌、手背和袖口；污染除顏色外，也有文字與圖示。

肩、肘透過手臂反向運動學對準器材握點，手腕與手指使用操作姿勢混合。這是新增能力；現有模型雖然具備肩肘結構，尚未有這套手部連動。

每件器材建立明確的握點、使用端與支撐點。例如鏟斗握把、推板握塊、瓶身握區、吸附墊兩側、袋口兩側。單件物品雙手支撐時只設一個物理主控制者，另一手依物品實際位置配合；鏟斗與推板同時操作時，各物品各有一個控制者，再由操作狀態協調。

物件仍交給現有 Havok 抓取與碰撞系統更新。物理更新後，雙手對準器材的實際握點，避免物品卡住時手仍穿過器材或離開握把。超出手臂可及範圍就提示靠近；處理地面時加入可控制的蹲下／俯身操作姿勢。

| 操作 | 必須看見的動作與結果 |
| --- | --- |
| 搬警示牌 | 手抓住握區，另一手輔助展開；放手後立牌穩定站立 |
| 穿戴防護裝備 | 依核定 PPE 流程呈現手套與袖口接合、裝備檢查；更新實際角色狀態 |
| 開處理包 | 一手扶箱、一手打開，器材被取出時可辨認其用途 |
| 吸附／去污 | 手持核定器材，使用端對準目標；腕部方向與實際器材方向一致 |
| 擦拭 | 掌面壓住墊，移動方向、接觸區域與清理結果同步 |
| 鏟取與倒入袋 | 手握鏟斗／推板，抬高與前傾可見；顆粒實際進袋才算處置進度 |
| 封袋及脫除 | 雙手在袋口進行封合，脫除時能看見如何避免污染部位接觸乾淨部位 |

**每站都形成「理解 → 示範 → 操作 → 解釋結果」**

保留既有五個空間區域，再於入口／出口安排簡短情境導入與結束區。物理站點與七個流程步驟分開建模：一個清理區可以包含多個步驟，避免只把七步清單換成七張告示。

| 區域 | 學員要取得的操作知識 | 互動及回饋 |
| --- | --- | --- |
| 入口／情境導入 | 判斷環境潑灑、辨認污染區、知道何時求援及通報 | 簡短事件描述，選擇第一個行動，再進入情境 |
| A 示警 | 警示與隔離的目的、擺放位置及安全接近路徑 | 搬運、展開、放置；回饋位置與狀態，不只顯示完成打勾 |
| B 防護 | 每項 PPE 的用途、核定穿戴順序、手套與袖口的關係 | 近看裝備、觀察手部示範、親手完成與檢查；錯誤說明暴露風險及補救 |
| C 處理包 | 辨識用品、乾淨區管理、工具選擇及更換時機 | 開包、取物、器材知識卡；錯誤用品與污染接觸有原因說明 |
| 中央清理區 | 吸附／圍堵、收集、依核定 SOP 去污與清潔 | 依操作順序顯示手部姿勢、器材方向、接觸區域；結果由實際互動狀態決定 |
| D 廢棄物區 | 收集、封合、使用正確容器及避免交叉污染 | 觀察袋口、投放與踏板動作；辨識未封袋、污染接觸等問題 |
| 出口／結束區 | 安全脫除、手部衛生、暴露處理與事件紀錄 | 逐步手部操作及簡短回顧；回到操作錯誤處重練 |

每站的常駐提示限制為「目前目標、現在動作、成功條件」，完整知識卡按需展開。示範可以暫停和重播；看過示範與完成實作分別記錄，觀看不會自動完成操作。

教學模式提供目標提示、操作示範與可補救練習。測驗模式保留基本控制說明，隱藏解題提示，結束後依操作紀錄解釋。評估以流程判斷、實際操作及污染控制為主，時間作為參考。

**操作介面建議**

走動時使用 WASD 與滑鼠視線；中央小準星顯示目前看向的器材名稱、是否可及及可用動作。靠近站點後，以同一動作名稱提供快捷鍵與按鈕入口。

建議以 F 互動，G 放下，Q／E 保留前後傾斜。拿取後進入搬運狀態，手握實體物品隨角色移動；精細操作時進入站點操作狀態，提供清楚的手部取景與控制提示。開啟知識卡、按 Esc 或失去焦點時，停止走動／持續傾倒等輸入並釋放滑鼠鎖定，關卡狀態保留。

各站動作應由同一份資料生成提示與按鈕，消除目前「開蓋／打開／踩踏板」的名稱落差。右側完整流程改為可展開的進度卡，底部只顯示當前狀態適用的少量控制。

**明亮、溫暖的環境**

空間定位為白天的臨床模擬教學室。以暖白牆面、淺米灰霧面地板、柔和木色櫃面及鼠尾草綠站牌建立親切感。大窗框、窗外淺色天空、柔光燈具與少量壁面圖示均以程序化幾何／DynamicTexture 製作。

| 元素 | 建議色彩 | 用法 |
| --- | --- | --- |
| 暖白 | `#F7F4EC` | 牆面、教學卡背景 |
| 米灰 | `#E6DFD2` | 霧面地板，使用低對比大塊分縫 |
| 淺木色 | `#CFAF87` | 櫃面與招牌邊框的視覺飾面 |
| 鼠尾草綠 | `#91AA97` | 站點色帶、柔和區域識別 |
| 深綠灰 | `#263C36` | 主要文字與操作標題 |
| 琥珀色 | `#D6942A` | 區域警示，配合圖示和文字 |
| 污染提示色 | `#A14463` | 手部／器材污染狀態；教學視覺需註明為示意 |

深色正文搭配淺色實底卡，避免白字直接疊在日光場景。提示文字以 16–18 px 作起點，站牌在站外可辨識；中央及下半部留給雙手、工具和地面操作。對比以最後合成畫面驗證。

工具集中在高度合適的工作檯／處理車，具名稱及輪廓定位。清潔準備區、操作區與廢棄物區有清楚的空間標示。處理污染物的位置保留可接近、可蹲下及雙手施作的空間。

光照採柔和環境光與暖色方向光，陰影用於辨識工具離地高度、抓握接觸與桶口位置。陰影品質提供可調設定，粒子與鏡頭後方裝飾不全部投入高成本陰影。亮度、對比與效能需在實作後量測，本次沒有改版 FPS 數據。

**教學內容需與畫面一起校正**

目前遊戲將「撒粉 → 噴消毒劑 → 擦乾」固定為通用流程，並用 `disinfected` 百分比表示進度。正式操作教學應依選定藥品、潑灑處理包及院內 SOP 描述適用處理方式，明確區分去活化、去污、清潔與消毒。這項設計建議依據 NIOSH 對危害性藥物暴露控制、PPE 與潑灑清理的說明；遊戲粒子比例不代表化學去污效果。[NIOSH，Managing Hazardous Drug Exposures: Information for Healthcare Settings（2023）](https://www.cdc.gov/niosh/docs/2023-130/2023-130.pdf)

PPE 也需要表達危害性藥物適用性及情境要求，目前三個裝備旗標不足以呈現全部操作知識。內外層手套與袖口關係可做為可見雙手教學的重點。[OSHA，Pharmacy Personal Protective Equipment](https://www.osha.gov/etools/hospitals/pharmacy/personal-protective-equipment)

另有三項現有判定應在教學改版時一起處理：

- 手套污染目前由物件類別直接判定；拿起初始乾淨的工具也立即污染。應區分器材初始狀態及後續接觸事件。
- 踏入污染區目前只在未穿齊 PPE 時記錯。需依實際接觸追蹤污染，避免產生穿齊後可任意踩入的暗示。
- `doff()` 只檢查投桶步驟即可結束；擦拭即使順序錯誤仍標記該步完成。應分開表示「做過」「正確」「需補救」，結束摘要依完整過程評估。

這些是依當前原始碼發現的教學設計落差，本次尚未改寫判定。院內 SOP 未提供，建議稿不自行指定特定清潔藥劑、濃度或接觸時間。

**實作順序與驗收**

先完成第一人稱、保留人偶、可見雙手與一個真實抓握範例，再把握點和姿勢套用到各站；接著整合逐站知識與回饋，最後統一明亮環境及完成全流程驗收。這三階段共同涵蓋本次需求。

主要落點是 `../playground/src/training/` 的鏡頭、玩家、提示、UI、場景及流程。手部姿勢、器材握點和站點教材適合新增獨立模組。物理部分重用 `grabController.ts` 與 `interactions.ts`；共同的動作識別資料由 `actions.ts` 提供。人偶外觀若需新增構件，優先以訓練專用選項／附屬視覺處理，維持共享模型契約清楚。

驗收至少包含：

- 第一人稱走遍各站，視角不被自己的頭髮、前牆或面板遮擋；手與器材清楚可見。
- 手掌、手背、袖口的手套及污染狀態一致；握點誤差、關節限制與雙手分工有檢查。
- 拿取、移動、使用、放下及失焦恢復順暢；物品碰牆時手部姿勢與物理位置一致。
- 示範不會替使用者完成步驟；每站能說明目的、操作、成功條件及補救方式。
- 教學與測驗採相同操作判定；完成摘要能辨識流程完整性與需重練項目。
- 跑過 TypeScript、現有場景／訓練／跑酷回歸，以及新增手部、第一人稱與站點互動檢查。
- 實際以鍵鼠完整走完一次，保存雙手操作、污染狀態與完成畫面的證據；量測目標裝置的效能與文字可讀性。

本次評估已可供確認方向。遊戲實作、臨床 SOP 套用和上線尚未執行。

# 女性角色第 5 輪：頭臉與斜瀏海

本輪沿用 female-tactical 與原參考圖，保留 125 個可選取、可展開的零件 ID。使用 Codex CLI 修改程序配方，再由桌面瀏覽器擷取實際 Babylon WebGL PNG，逐版檢查。

## 修改與失敗紀錄

- C1：調整眼裂、嘴寬、下臉與頸部比例，增加馬尾量體。正面與左右特寫確認比例有改善，仍有髮帽感與簡化五官。
- C2：延長斜瀏海、錯開髮束尖端並調整眉尾。鼻部加強過度，實際渲染出現鼻下寬黑帶，拒絕保留該鼻型。
- C3：移除鼻下強烈朝下的法線突變，數值改善，但渲染顯示鼻尖過平，拒絕採用。此例保留為「數值改善不等於視覺改善」的失敗紀錄。
- C4：最終實際渲染確認鼻下寬黑帶消除且鼻尖恢復。選擇 C1 頭部曲面搭配 C2 髮型與眉型，保留較穩定的組合，不繼續以猜測參數反覆增減鼻部凸起。

## 可重建與驗證邊界

每版有 author.py、rebuild.sh、修改清單、來源雜湊、相機與實際渲染。頭臉與髮型的編譯配方位於 `viewer/models/female-tactical/round5/compile_surfaces.py`，基礎輸入仍為模型 `spec.json`。C2、C3 與最終 C4 均從隔離暫存目錄重新生成相同執行資料。

維持相同相機與照明比較。沒有外部模型服務、生成式替代圖片、假造視覺通過、動畫綁定或 PBR 材質完成宣告。整體參考相似度仍未達門檻，衣服與護甲方塊感、五官表情、頭髮自然層次仍待後續改善。背面由單張圖片推測，不能視為原圖的直接證據。
